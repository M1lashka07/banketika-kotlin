# Банкетика

Учебный сайт управления заявками на банкеты для подготовки к демо-экзамену 2027 по веб-разработке. Требования основаны на описании пользователя, соответствие официальному КОД 2027 не заявляется.

Kotlin + Ktor, серверный HTML на kotlinx.html, PostgreSQL и Supabase Auth. PHP не используется. Подробные инструкции запуска и настройки будут добавлены вместе с реализацией.
